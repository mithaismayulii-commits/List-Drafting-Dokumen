Tutorial Deploy untuk Tim

Agar teman satu tim bisa mengakses web checklist ini lewat link internet (tanpa instalasi), Anda cukup mendistribusikannya via GitHub Pages atau Netlify Drop (Gratis & Sangat Mudah):

Cara 1: GitHub Pages (Paling Stabil)
  1. Simpan kode file ini dengan nama index.html di komputer Anda.
  2. Buat repository baru di github.com (Public).
  3. Upload file index.html tersebut ke repository Anda.
  4. Masuk ke menu Settings > Pages.
  5. Pada bagian Branch, pilih main / root, lalu klik Save.
  6. Link web Anda akan aktif dalam 1-2 menit dan bisa dibagikan ke tim!
Cara 2: Netlify Drop (Super Cepat 1 Menit)
  1. Buka situs drop.netlify.com.
  2. Drag & drop folder atau file index.html Anda ke halaman tersebut.
  3. Netlify akan langsung memberikan link web instan yang bisa langsung diakses tim Anda.
